如何贡献

让新贡献者知道路径，而不是只看见榜单。

01

Fork 仓库

从 GitHub Fork 项目，先拿到一份你自己的工作副本。

02

补充梗或视频

在数据文件中补充梗、视频、别名、描述或贡献者信息。

03

发起 Pull Request

提交 PR，等待 Actions 校验通过，让你的名字被正式记录进来。
