关于

一个纯粹的 B 站梗文化索引库。用户通过 PR 提交梗的出处视频和信息，自动化流程校验、排序、分发。没有广告，没有追踪，没有算法推荐。

只有梗，以及梗的来源。项目使用 GitHub Actions 自动校验 PR、生成排行榜、按收录视频数给梗授予修仙等级（从杂役弟子到渡劫飞升）。代码开源、MIT 协议。
