## これは何？

コミュニティで共同管理する **Bilibili「万恶の源」ミーム索引**です。

Bilibiliで大規模な二次創作・鬼畜・ミーム文化を巻き起こした「万恶の源」動画を収集し、修仙（せんしゅう）ランク体系で各ミームの流行度を格付けし、同時にコントリビューター全員に修仙称号を授与します。

**私たちは索引だけを作り、コンテンツ配信はしません。** すべての動画リンクはBilibiliの元ページを指しています。

## ミームの修仙ランク

各ミームのランクは、収録された関連動画の数によって自動計算されます。収録数が多いほど、そのミームは熱いということです：

| ランク | 収録数 | 説明 |
|--------|--------|------|
| 雑役弟子（ざつえきでし） | 0 ~ 2 | まだまだ少ない、どんどん追加しよう |
| 練気期（れんきき） | 3 ~ 5 | 頭角を現す |
| 築基期（ちくきき） | 6 ~ 10 | 少し名が知られる |
| 金丹期（きんたんき） | 11 ~ 20 | 界隈では誰もが知る存在 |
| 元嬰期（げんえいき） | 21 ~ 35 | 界隈の壁を越えて一般層へ |
| 化神期（かしんき） | 36 ~ 50 | サイト全体を席巻 |
| 練虚期（れんきょき） | 51 ~ 75 | 社会現象級 |
| 合体期（がったいき） | 76 ~ 100 | 支配級 |
| 大乗期（だいじょうき） | 101 ~ 149 | 伝説級 |
| 渡劫飛昇（とこうひしょう） | 150+ | Bilibili永遠の伝説 |

「渡劫飛昇」に到達したミームは **栄誉殿堂** 入りとなり、専用の展示ページが与えられます。

## コントリビューター称号

あなたが投稿した動画の収録数が増えるほど、称号も上がります：

| 称号 | 貢献回数 |
|------|----------|
| 雑役弟子（ざつえきでし） | 1 ~ 4 |
| 外門弟子（がいもんでし） | 5 ~ 14 |
| 内門弟子（ないもんでし） | 15 ~ 29 |
| 真伝弟子（しんでんでし） | 30 ~ 49 |
| 長老（ちょうろう） | 50 ~ 99 |
| 太上長老（たいじょうちょうろう） | 100+ |

すべての称号はGitHub Actionsが貢献データに基づいて自動計算します。特別扱いは一切ありません。

## クイックスタート

このプロジェクトに貢献したい？ たったの3ステップです：

**ステップ1：** このリポジトリをFork

**ステップ2：** `memes/` ディレクトリにYAMLファイルを作成または編集

```yaml
name: 梗的名称
aliases: ["别名1", "别名2"]
origin_video: "https://www.bilibili.com/video/BVxxxxxxxxxx"
description: "一句话描述这个梗的来龙去脉"
tags: ["鬼畜", "影视剪辑"]

videos:
  - bvid: "BVxxxxxxxxxx"
    title: "视频标题"
    author: "UP主名称"
    description: "简要描述"
    contributor: "你的GitHub用户名"
```

**ステップ3：** Pull Requestを作成し、自動チェックとレビューを待つ

詳細なルールは [貢献ガイド](CONTRIBUTING.md) をご覧ください。

## 機能一覧

- **修仙ランク体系** — 収録数でミームを自動格付け、雑役弟子から渡劫飛昇まで
- **コントリビューター称号** — 貢献すればするほど称号が上がる、コミュニティ報酬システム
- **データと表示の分離** — YAMLは生データのみ保持、ランキングとランクはActionsが自動計算
- **PR自動チェック** — フォーマット検証・重複検出・ランク変動プレビュー ✅
- **栄誉殿堂** — 渡劫飛昇ランクのミームに専用展示ページを提供 ✅
- **GitHub Pages** — 美しいオンラインブラウジングページ ✅
- **コントリビューターランキング** — 自動生成、全員の称号と貢献数を表示 ✅
- **多言語対応** — 中文 / English / 日本語
