## 这是什么

一个由社区共同维护的 **B站万恶之源梗索引**。

我们收集那些在B站引发大规模二创、鬼畜、玩梗的"万恶之源"视频，用修仙等级体系给每个梗的火爆程度分级，同时给每位贡献者授予修仙称号。

**我们只做索引，不做内容分发。** 所有视频链接指向B站原始页面。

## 梗的修仙等级

每个梗的等级由收录的相关视频数量自动计算，收录越多，说明这个梗越火：

| 等级 | 收录数 | 说明 |
|------|--------|------|
| 杂役弟子 | 0 ~ 2 | 太少了，快来补充 |
| 练气期 | 3 ~ 5 | 初露锋芒 |
| 筑基期 | 6 ~ 10 | 小有名气 |
| 金丹期 | 11 ~ 20 | 圈内皆知 |
| 元婴期 | 21 ~ 35 | 出圈利器 |
| 化神期 | 36 ~ 50 | 全站刷屏 |
| 练虚期 | 51 ~ 75 | 现象级 |
| 合体期 | 76 ~ 100 | 统治级 |
| 大乘期 | 101 ~ 149 | 传说级 |
| 渡劫飞升 | 150+ | B站永远的传说 |

达到「渡劫飞升」的梗将进入 **荣誉殿堂**，获得专属展示页面。

## 贡献者称号

你提交的视频收录越多，称号越高：

| 称号 | 贡献次数 |
|------|----------|
| 杂役弟子 | 1 ~ 4 |
| 外门弟子 | 5 ~ 14 |
| 内门弟子 | 15 ~ 29 |
| 真传弟子 | 30 ~ 49 |
| 长老 | 50 ~ 99 |
| 太上长老 | 100+ |

所有称号由 GitHub Actions 根据贡献数据自动计算，不搞特殊化。

## 快速开始

想给这个项目添砖加瓦？只需三步：

**第一步：** Fork 本仓库

**第二步：** 在 `memes/` 目录下创建或编辑 YAML 文件

```yaml
name: 梗的名称
aliases: ["别名1", "别名2"]
origin_video: "https://www.bilibili.com/video/BVxxxxxxxxxx"
description: "一句话描述这个梗的来龙去脉"
tags: ["鬼畜", "影视剪辑"]

videos:
  - bvid: "BVxxxxxxxxxx"
    title: "视频标题"
    author: "UP主名称"
    description: "简要描述"
    contributor: "你的GitHub用户名"
```

**第三步：** 提交 Pull Request，等待自动检查和审核

详细规范请看 [贡献指南](CONTRIBUTING.md)。

## 功能特性

- **修仙等级体系** — 用收录数量自动给梗分级，从杂役弟子到渡劫飞升
- **贡献者称号** — 贡献越多称号越高，社区激励
- **源数据与展示分离** — YAML 只存原始数据，排行榜和等级由 Actions 自动计算
- **PR 自动检查** — 格式校验、查重、等级变化预览 ✅
- **荣誉殿堂** — 渡劫飞升级别的梗获得专属展示（开发中）
- **GitHub Pages** — 精美的在线浏览页面（开发中）
- **贡献者排行榜** — 自动生成，展示每位贡献者的称号和贡献数 ✅
- **多语言支持** — 中文 / English / 日本語
